ReadmitIQ — Patient Readmission Risk Analyzer

Problem: 30-day hospital readmissions cost healthcare systems over $26B annually while increasing patient mortality. Identifying high-risk patients from unorganized EHR datasets is complex and prone to human error.

Solution & Architecture:

  • Architected a 6-table MySQL star schema data warehouse (dim_patient, dim_diagnosis, dim_medication, dim_hospital, fact_admissions, fact_shap_scores) ETL pipeline processing 100,000+ patient EHR records.
  • Trained an XGBoost classification model with SMOTE class balancing across 11 clinical features in 5-fold cross-validation, achieving 0.65 ROC-AUC and 43.4% recall.
  • Calculated 100% dynamic patient-level SHAP risk explanations and containerized a sub-100ms FastAPI REST API using Docker & Docker Compose.
  • Designed a 4-page Power BI dashboard (Executive Overview, Clinical Risk, Patient Explorer, Model Performance).

DriveGuard — Driver State Monitoring & Safety Analytics

Problem: Commercial driver drowsiness and distraction account for over 20% of serious highway accidents, yet fleets lack real-time computer vision alerts and automated post-drive forensic auditing.

Solution & Architecture:

  • Engineered a 30 FPS real-time vision pipeline using OpenCV and MediaPipe 3D Face Mesh tracking Eye Aspect Ratio (EAR < 0.23) and Mouth Aspect Ratio (MAR > 0.6).
  • Implemented a 0–100% fatigue scoring engine incorporating blink frequency, yawning, and 3D head pose vectoring (Yaw/Pitch/Roll).
  • Built an escalating safety system triggering local audio sirens, voice break timers, and automated SMTP emergency SOS emails within 15s of unresponsiveness with 5-second .mp4 evidence capture.
  • Developed a post-drive forensic engine (session_analysis.py) processing continuous 10-metric CSV telemetry logs to generate 3 Matplotlib trend charts, Gemini AI recommendations, and print-ready A–F graded PDF safety reports.
