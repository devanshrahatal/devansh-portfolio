## Featured Data Analytics Projects

### 1. ReadmitIQ — Patient Readmission Risk Analyzer
- **Domain**: Healthcare Data Analytics & Predictive Risk Modeling
- **Architecture**: 6-table MySQL star schema ETL data warehouse processing 100,000+ EHR records.
- **Implementation**: XGBoost classification model with SMOTE class balancing (0.65 ROC-AUC, 43.4% recall) and sub-100ms FastAPI REST API containerized using Docker.
- **Visualization**: 4-page interactive Power BI dashboard covering Executive Overview, Clinical Risk, Patient Explorer, and Model Performance.

### 2. DriveGuard — Driver State Monitoring & Safety Analytics
- **Domain**: Computer Vision & Telemetry Forensic Analytics
- **Architecture**: 30 FPS real-time vision pipeline utilizing OpenCV and MediaPipe 3D Face Mesh tracking Eye Aspect Ratio (EAR < 0.23) and Mouth Aspect Ratio (MAR > 0.6).
- **Implementation**: 0–100% fatigue scoring engine triggering escalating local audio sirens and automated SMTP emergency SOS emails within 15 seconds.
- **Visualization**: Forensic analytics engine processing continuous 10-metric CSV logs into Matplotlib trend charts and A–F graded PDF safety reports.

### 3. Zomato Operations Intelligence — Executive & Logistics Dashboard
- **Domain**: Logistics Analytics & Business Intelligence
- **Architecture**: Production MySQL star schema warehouse featuring 7 dimension tables and 2 fact tables (`fact_orders`, `fact_payments`).
- **Implementation**: Python data simulation pipeline modeling 18 months of logistics operations (119,994 orders, 123,275 payment attempts across 15 Indian cities).
- **Visualization**: 38 custom DAX measures powering a 3-page Power BI dashboard (Executive & Financial, Operations & Delivery, Customer Behavior & Churn).
